# Mando

Control remoto premium (modo oscuro) para Chromecast con Google TV, hecho en Android.

- Busca el Chromecast en el WiFi (mDNS) o por IP
- Emparejamiento con código de 6 caracteres (protocolo Android TV Remote v2)
- Anillo direccional o panel táctil, inicio, atrás, volumen, reproducción, encendido, ajustes
- Teclado para escribir en los buscadores de la TV y accesos directos a apps

El APK se compila solo con GitHub Actions y queda en **Releases**.
